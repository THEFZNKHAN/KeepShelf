# Bundled fonts

- **Geist-Variable.woff2**: Geist by Vercel, SIL Open Font License 1.1 (https://github.com/vercel/geist-font).
  Used on Windows and Linux; macOS uses its own system font.
- **MaterialSymbolsRounded-subset.woff2**: Material Symbols Rounded by Google, Apache License 2.0
  (https://github.com/google/material-design-icons). Cut down to the names in `src/popup/icon-names.txt` by
  `scripts/fetch-icon-font.mjs`.
