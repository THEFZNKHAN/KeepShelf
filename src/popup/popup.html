    play_circle Watch sites None expand_more

    Optional. Add a site where you watch, and each title gets a button that opens its page there. None are included, and KeepShelf never visits the site: it only builds the link.

    How it works

    Paste the address of one title's page and say which title it is. KeepShelf works out how the site builds its addresses and uses that for every other title.

    If the site has an address style that works for both movies and series, use that one and you only need a single page.

    Sites that use ids need a TMDB id or an IMDb id for the title, so set up your TMDB token above and fetch info for your shelf first, then pick a title that has info.

    If a site's title addresses can't be worked out (some add random letters), paste a search results page for one title instead, and each title gets a button that opens that site's search. Search for a title with two or more words. For a title like "One Piece: Wan pîsu", search for the part before the colon, "One Piece", and pick that title.

    If the address is an episode page (such as …/one-piece-episode-1180), the link opens the next episode you haven't watched, or episode 1 if you haven't started. Keep your episode progress up to date and the link follows it.
